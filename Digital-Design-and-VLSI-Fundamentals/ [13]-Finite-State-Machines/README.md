# 13. Finite State Machines (FSM)

[![Stage](https://img.shields.io/badge/Stage-A--Digital--Design-blue.svg)](#)
[![Focus](https://img.shields.io/badge/Focus-Finite%20State%20Machines-orange.svg)](#)

This module introduces Finite State Machines (FSMs), one of the most important concepts in sequential digital system design. It covers FSM fundamentals, state representation, Moore and Mealy machines, FSM design methodology, and sequence detector implementation.

Finite State Machines are extensively used in digital controllers, communication protocols, processors, embedded systems, FPGA/ASIC designs, and RTL development.

---

## 🎯 Learning Objectives

By working through this module, you will be able to:

- Understand the fundamentals of Finite State Machines (FSMs).
- Explain why FSMs are required in sequential digital systems.
- Design and interpret state diagrams and state tables.
- Differentiate between Moore and Mealy state machines.
- Learn the standard FSM design procedure.
- Design sequence detectors using FSM concepts.
- Build a strong foundation for RTL design and digital controllers.

## 🛠️ Core Concepts Covered

### 1. Finite State Machines

Understand Finite State Machines as sequential digital systems whose outputs depend on the current state and input conditions.

### 2. State Representation

Learn how state diagrams and state tables are used to model, visualize, and analyze the behavior of sequential systems.

### 3. Moore and Mealy Machines

Study the characteristics, operation, advantages, disadvantages, and practical differences between Moore and Mealy state machines.

### 4. FSM Design Procedure

Understand the complete FSM design flow, including problem analysis, state identification, state diagram creation, state table generation, state assignment, logic implementation, and verification.

### 5. Sequence Detectors

Learn how FSMs are used to design sequence detectors for recognizing predefined binary input patterns in digital communication and control systems.

### 6. Practical Applications

Explore the use of FSMs in traffic light controllers, vending machines, communication protocols, UART controllers, processors, digital controllers, embedded systems, and FPGA/ASIC RTL design.
