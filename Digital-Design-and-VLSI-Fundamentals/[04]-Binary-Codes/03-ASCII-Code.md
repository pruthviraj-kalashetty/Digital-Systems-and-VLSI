# **ASCII Code**

* **Overview**

**ASCII (American Standard Code for Information Interchange)** is a character encoding system used to represent letters, numbers, punctuation marks, and control characters using binary codes. It is an important concept under **Binary Codes** and is widely used in computers, digital systems, communication systems, and text processing.

---

* **Definition**

**ASCII** is a character encoding standard in which each character is assigned a unique numerical code. Standard ASCII uses **7 bits** to represent **128 different characters**, including uppercase letters, lowercase letters, digits, symbols, and control characters.

---

* **Why is ASCII Code Needed?**
  - To represent characters in digital systems.
  - To allow computers to store text as binary data.
  - To enable communication between digital devices.
  - To provide a standard representation for characters.
  - To convert characters into numerical and binary values.
  - To support text processing and data transmission.

---

* **Characteristics**
  - ASCII stands for **American Standard Code for Information Interchange**.
  - Standard ASCII uses **7 bits**.
  - It can represent **128 different characters**.
  - ASCII values range from **0 to 127**.
  - It includes printable and non-printable characters.
  - Each character has a unique numerical value.
  - ASCII can be represented in decimal, hexadecimal, or binary form.

---

* **ASCII Character Categories**

ASCII characters can broadly be divided into:

  - **Control Characters**
    - ASCII values: **0–31**
    - Used for controlling devices and communication.

  - **Printable Characters**
    - ASCII values: **32–126**
    - Include spaces, letters, numbers, and symbols.

  - **DEL Character**
    - ASCII value: **127**
    - Used as a control character.

* **ASCII Conversion Example**

Consider the character:

**A**

ASCII value:

**A = 65₁₀**

Convert 65 to binary:

**65 = 1000001₂**

Therefore:

**A → 1000001**

Hexadecimal:

**A → 41₁₆**

* **ASCII vs BCD**

ASCII and BCD are different coding systems.

| Feature | ASCII | BCD |
|---|---|---|
| Purpose | Character representation | Decimal digit representation |
| Standard Size | 7 bits | 4 bits per decimal digit |
| Characters | Letters, digits, symbols, controls | Decimal digits |
| Range | 0–127 | 0–9 per 4-bit group |
| Main Use | Text and communication | Decimal displays and arithmetic |
| Example of 5 | ASCII = 0110101 | BCD = 0101 |

For the character **5**:

**ASCII '5' = 0110101**

**BCD 5 = 0101**

Therefore, ASCII and BCD should not be confused.

---

* **ASCII vs Binary**

ASCII is a **character encoding**, while binary is a **number representation system**.

For example, the decimal number:

**65**

as pure binary is:

**1000001₂**

ASCII uses the same numerical code to represent the character:

**'A'**

Therefore:

**ASCII 65 → Character 'A'**

The meaning depends on whether the value is interpreted as a character code or a numerical value.

---

* **Extended ASCII**

Standard ASCII uses **7 bits** and provides **128 codes**.

Some systems historically used **8-bit character sets** commonly called **Extended ASCII**, providing up to **256 values**.

However, there is no single universal "Extended ASCII" standard. Different systems used different 8-bit extensions.

Therefore:

**Standard ASCII → 7 bits → 128 codes**

**8-bit extensions → 256 possible values, but encoding depends on the specific character set**

* **Advantages**
  - Simple and easy to understand.
  - Provides a standardized character representation.
  - Easy to convert between character, decimal, hexadecimal, and binary forms.
  - Widely supported by computers and digital systems.
  - Useful for text transmission and storage.
  - Efficient for basic English characters.

---

* **Limitations**
  - Standard ASCII supports only 128 codes.
  - It does not represent most non-English writing systems.
  - It is insufficient for modern multilingual text.
  - Extended 8-bit character sets are not universally standardized.
  - Modern systems generally use Unicode for broader character support.

* **Real-World Example**

When a user types the letter:

**A**

a computer can represent it internally using the ASCII value:

**A = 65₁₀**

Binary representation:

**1000001₂**

Hexadecimal representation:

**41₁₆**

Therefore, the character can be represented as:

**A → 65 → 41₁₆ → 1000001₂**

This allows digital hardware and software to store and process the character as numerical data.

* **Interview Questions**

**1. What is ASCII?**

**Answer:**

ASCII stands for **American Standard Code for Information Interchange**. It is a character encoding standard used to represent letters, numbers, symbols, and control characters using numerical codes.

---

**2. How many bits does standard ASCII use?**

**Answer:**

Standard ASCII uses **7 bits**.

---

**3. How many characters can standard ASCII represent?**

**Answer:**

7 bits can represent:

**2⁷ = 128**

Therefore, standard ASCII provides **128 codes**.

---

**4. What is the ASCII value of uppercase A?**

**Answer:**

**A = 65₁₀ = 41₁₆ = 1000001₂**

---

**5. What is the ASCII value of lowercase a?**

**Answer:**

**a = 97₁₀ = 61₁₆ = 1100001₂**

---

**6. What is the ASCII value of character 0?**

**Answer:**

The ASCII value of the character **'0'** is:

**48₁₀ = 30₁₆ = 0110000₂**

---

**7. What is the difference between ASCII '5' and BCD 5?**

**Answer:**

ASCII represents the character **'5'** using:

**0110101**

BCD represents the decimal digit **5** using:

**0101**

Therefore, they are different encodings.

---

**8. What is the difference between ASCII and Unicode?**

**Answer:**

ASCII is a limited character encoding system containing 128 standard codes, while Unicode is a much larger character encoding standard designed to represent characters from many writing systems.

---

**9. What are ASCII control characters?**

**Answer:**

ASCII control characters are non-printable characters used for communication and device control. Examples include **NUL, TAB, LF, CR, ESC, and DEL**.

---

**10. What is the ASCII value range?**

**Answer:**

Standard ASCII values range from:

**0 to 127**

---

**11. What is the range of printable ASCII characters?**

**Answer:**

The commonly defined printable ASCII range is:

**32 to 126**

---

**12. What is Extended ASCII?**

**Answer:**

Extended ASCII is a general term historically used for various 8-bit character sets that extend ASCII-like encodings to 256 possible values. It is not one single universal standard.

---

**13. Why is ASCII important in digital systems?**

**Answer:**

ASCII provides a standardized way to represent characters as numerical and binary data, allowing computers, microcontrollers, communication systems, and digital hardware to store and transmit text.

---

**14. Where is ASCII used?**

**Answer:**

ASCII is used in computers, serial communication, UART, embedded systems, terminals, text files, communication protocols, FPGA, ASIC, and digital systems.
