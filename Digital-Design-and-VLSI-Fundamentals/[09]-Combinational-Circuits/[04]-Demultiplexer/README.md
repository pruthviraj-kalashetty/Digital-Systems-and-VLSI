# ◈ Demultiplexers

[![Stage](https://img.shields.io/badge/Combinational--Circuits-blue.svg)](#)
[![Focus](https://img.shields.io/badge/Focus-Demultiplexers-orange.svg)](#)

This module introduces demultiplexers (DEMUX), fundamental combinational circuits that route a single input signal to one of several output lines based on the values of selection lines. It covers 1×2, 1×4, and 1×8 demultiplexers, their logic implementation, truth tables, Boolean expressions, and practical applications in digital systems.

Demultiplexers are essential components in digital electronics and are widely used in communication systems, memory addressing, data distribution, processor architectures, FPGA/ASIC designs, and digital control systems.

---

## 🎯 Learning Objectives

By working through this module, you will be able to:

- Understand the working principle of demultiplexers.
- Analyze the relationship between data input, select lines, and outputs.
- Design 1×2, 1×4, and 1×8 demultiplexers.
- Understand the Boolean implementation of demultiplexers.
- Build the foundation for data routing and distribution in digital systems.

## 🛠️ Core Concepts Covered

### 1. Demultiplexer Fundamentals

Understand demultiplexers as combinational circuits that route a single input signal to one of several output lines using selection lines.

### 2. 1×2 Demultiplexer

Study the simplest demultiplexer with one data input, one select line, and two outputs, including its truth table and Boolean expressions.

### 3. 1×4 Demultiplexer

Learn the operation of a 1×4 demultiplexer that distributes one input signal to one of four outputs using two select lines.

### 4. 1×8 Demultiplexer

Understand the design and operation of a 1×8 demultiplexer using three select lines to control eight output lines.

### 5. Practical Applications

Explore the use of demultiplexers in data distribution, communication systems, memory addressing, processor architectures, digital control systems, FPGA/ASIC designs, and signal routing.
