# Adders

[![Stage](https://img.shields.io/badge/Combinational--Circuits-blue.svg)](#)
[![Focus](https://img.shields.io/badge/Focus-Adders-orange.svg)](#)

This module introduces adders, the fundamental combinational circuits used to perform binary addition in digital systems. It covers the Half Adder, Full Adder, and the implementation of a Full Adder using two Half Adders. These circuits form the foundation of arithmetic logic units (ALUs), processors, digital signal processing systems, and RTL design.

Understanding adder circuits is essential before studying ripple carry adders, carry look-ahead adders, arithmetic circuits, and processor datapaths.

---

## 🎯 Learning Objectives

By working through this module, you will be able to:

- Understand the fundamentals of binary addition.
- Analyze the operation of Half Adders and Full Adders.
- Understand carry generation and propagation.
- Implement a Full Adder using two Half Adders.
- Build the foundation for arithmetic circuit and RTL design.

## 🛠️ Core Concepts Covered

### 1. Binary Addition

Understand the rules of binary addition and how digital circuits perform arithmetic operations using logic gates.

### 2. Half Adder

Study the Half Adder, which adds two single-bit binary inputs and produces Sum and Carry outputs without considering a carry input.

### 3. Full Adder

Learn the operation of the Full Adder, which adds three binary inputs (A, B, and Carry-In) to generate Sum and Carry-Out outputs.

### 4. Full Adder Using Two Half Adders

Understand how two Half Adders and one OR gate can be combined to implement a Full Adder, demonstrating hierarchical digital circuit design.

### 5. Practical Applications

Explore the use of adders in Arithmetic Logic Units (ALUs), processors, multipliers, digital signal processors (DSPs), microcontrollers, and FPGA/ASIC designs.
