# Encoders

[![Stage](https://img.shields.io/badge/Stage-A--Digital--Design-blue.svg)](#)
[![Focus](https://img.shields.io/badge/Focus-Encoders-orange.svg)](#)

This module introduces encoders, fundamental combinational circuits that convert one of multiple active input lines into a corresponding binary output code. It covers 4×2 and 8×3 encoders, including their truth tables, Boolean expressions, logic implementation, and practical applications in digital systems.

Encoders are widely used in data encoding, interrupt systems, keyboard interfaces, communication systems, control logic, and FPGA/ASIC designs.

---

## 🎯 Learning Objectives

By working through this module, you will be able to:

- Understand the working principle of binary encoders.
- Analyze the relationship between input lines and encoded binary outputs.
- Design and analyze 4×2 and 8×3 encoders.
- Understand encoder truth tables and Boolean expressions.
- Build a foundation for digital encoding and control logic.

## 🛠️ Core Concepts Covered

### 1. Encoder Fundamentals

Understand encoders as combinational circuits that convert one active input among multiple input lines into a corresponding binary output code.

### 2. 4×2 Encoder

Study how four input lines are encoded into a two-bit binary output and analyze its truth table and Boolean expressions.

### 3. 8×3 Encoder

Learn how eight input lines are encoded into a three-bit binary output and understand its logic implementation.

### 4. Encoder Logic

Understand how Boolean logic gates are used to implement encoder circuits and generate the required binary output.

### 5. Practical Applications

Explore the use of encoders in keyboard interfaces, interrupt controllers, data encoding, communication systems, control circuits, processor systems, and FPGA/ASIC designs.
