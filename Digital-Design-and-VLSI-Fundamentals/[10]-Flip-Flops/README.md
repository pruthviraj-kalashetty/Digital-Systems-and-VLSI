# 10. Flip-Flops

[![Stage](https://img.shields.io/badge/Digital--Design--and--VLSI--Fundamentals-blue.svg)](#)
[![Focus](https://img.shields.io/badge/Focus-Sequential%20Logic-orange.svg)](#)

This module introduces the fundamental storage elements used in sequential digital circuits: flip-flops. It covers SR, D, JK, and T flip-flops along with latch concepts, operating principles, truth tables, characteristic tables, and applications in digital systems.

Flip-flops are essential building blocks for registers, counters, memory elements, finite state machines (FSMs), and sequential RTL designs implemented using Verilog HDL.

---

## 🎯 Learning Objectives

By working through this module, you will be able to:

- Understand the difference between latches and flip-flops.
- Analyze the operation of different types of flip-flops.
- Understand truth tables and characteristic behavior of flip-flops.
- Learn how binary data is stored and transferred in sequential circuits.
- Build the foundation for registers, counters, FSMs, and RTL sequential design.

## 🛠️ Core Concepts Covered

### 1. Latches

Understand level-triggered storage elements such as SR Latch and D Latch, which store a single bit of information based on enable conditions.

### 2. SR Flip-Flop

Learn the basic Set-Reset storage element, including its set, reset, hold conditions, and the limitation of invalid input states.

### 3. D Flip-Flop

Understand the data storage element that captures input data on a clock edge and is widely used in registers and memory circuits.

### 4. JK Flip-Flop

Study the improved version of SR Flip-Flop that removes the invalid state and introduces toggle functionality.

### 5. T Flip-Flop

Learn the toggle operation of T Flip-Flop and its applications in counters, frequency division, and sequential circuits.
